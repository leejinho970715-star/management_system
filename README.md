# 신도림 신앙관리 시스템 화면설계 시안

2026-10-09 구축 기획서의 11개 메뉴, 47개 화면을 바탕으로 만든 로컬 웹 프로토타입입니다. 기획서의 문구는 요구사항 자료로 분석했으며, 문서에 있는 승인 요청이나 운영 지시를 실행하지 않았습니다.

사용자의 추가 요청에 따라 주 색상 `#0D9488`, Pretendard, 가벼운 블록 그림자, `1구역`~`10구역`을 반영했습니다. 개인정보와 업무 기록은 모두 가상 데이터입니다.

## 실행

Node.js가 있는 환경에서 프로젝트 폴더를 열고 실행합니다. 앱 실행에는 패키지 설치가 필요하지 않습니다.

```powershell
node server.mjs
```

브라우저에서 `http://127.0.0.1:4173`을 엽니다. 다른 포트는 `node server.mjs 4174`처럼 지정합니다. `npm start`도 같은 서버를 실행합니다. 서버 종료는 터미널에서 Ctrl+C를 누릅니다. `index.html`을 직접 열지 말고 서버를 사용하세요.

상단의 **시안 역할**에서 7개 역할을 전환합니다. 구역장은 담당 구역을 1~10구역 중 선택할 수 있습니다. 이 전환은 검토 기능입니다. 역할 변경은 실제 로그인 또는 권한 부여가 아닙니다.

## 산출물

- `output/pdf/신앙관리시스템_화면설계_와이어프레임_v1.pdf`: 73쪽 A3 가로 문서. 기획 분석 8쪽, 정의 화면 47쪽, 회원 카드 등 상세 변형 9쪽, 모바일 5쪽, 디자인 가이드·컬러 예시·브랜드 자산 4쪽.
- `app/`: 화면과 업무 흐름을 실행하는 소스 코드.
- `docs/설계결정.md`: 요구사항 해석, 미확정 기준 및 운영용 구현의 경계.
- `output/qa/verification.json`: 브라우저 검증 결과. QA 출력은 Git에서 제외됩니다.

- 주차·예배별 출석 입력과 동일 키 갱신, 미입력 표시, 현황 재계산, 장기결석 등재 시뮬레이션.
- 전도 대상자 등록, 단계 변경 이력, 접촉 기록과 최근 접촉일, 단계·이탈 현황.
- 심방과 후속조치 기한, 완료 처리, 구역장의 면담 요청, 지역장의 배정 및 처리.
- 구역예배, 교육 과정·회차 참석, 시험과 응시·점수 저장.

- 회의록, 담당 액션 상태 변경, 기한 경과 항목의 원본 연결 및 중복 없는 이월.
- 조직·직책·임기·계정·주차 기준정보, 운영 기준 설정, 개별 전체 이름 열람 사유와 시안 감사 로그.

## 데이터와 실제 운영의 경계

기록은 해당 브라우저의 `localStorage`에 저장됩니다. 새로고침 후에도 유지되지만 다른 기기나 브라우저와 공유되지 않습니다. 상단 안내 아이콘의 **가상 데이터 초기화**로 시안 데이터를 복구합니다. 이전 3구역 시안은 별도 저장키로 분리했으므로 수정한 가상 데이터를 덮어쓰지 않습니다.

실제 사용자 계정·이메일 인증, PostgreSQL·RLS, finance 스키마, 서버 감사 로그, 예약 배치, 개인정보 파기, 동시 수정 제어는 연결되어 있지 않습니다. 가상 데이터만 사용하세요. 메뉴 숨김과 프런트엔드 필터는 서버 보안을 대신하지 않습니다.

보고는 제출 당시의 수치를 복사해 유지합니다. 원본 출석을 변경한 뒤 보고를 다시 열어보면 차이를 확인할 수 있습니다. 미제출 구역은 0으로 계산하지 않습니다. 시안 날짜는 기획서 검토일인 2026-10-10, 주차는 2026년 41주로 시작합니다.

회계의 구역장 조회 범위가 원문에서 상충하므로 FN-04는 화면을 유지하고 납부 내역을 차단했습니다. 보관기간 및 익명화 정책 확정 전에는 개인정보 파기를 실행하지 않습니다. 다른 결정은 설계결정 문서와 PDF의 분석 부분에 정리했습니다.

## 검증과 문서 재생성

```powershell
node scripts/domain-test.mjs
```

브라우저 검증과 PDF 재생성 스크립트는 이 작업 호스트의 번들 Playwright, Chromium, Python, ReportLab, Poppler 경로를 사용합니다. 다른 호스트에서는 경로를 수정해야 합니다. `scripts/browser-qa.cjs`는 가상 데이터 입력·저장 검증과 47개 화면, 모바일 및 상세 탭 캡처를 만듭니다. `scripts/build_wireframes.py`는 캡처와 메타데이터로 PDF를 생성합니다. PDF용 Pretendard 정적 인스턴스 생성에는 FontTools와 Brotli가 필요합니다.

## 로고와 공유 이미지

제공 이미지를 `app/assets/logo.jpg`에 원본 그대로 복사해 페이지 로고와 로그인 화면에 적용했습니다. `favicon.ico`에는 16/32/48/64px, PNG favicon은 32px, 터치 아이콘은 180px입니다. 공유 이미지는 `app/assets/og-image.png`, 1200×630px이며 built-in image_gen으로 만들었습니다. 최종 프롬프트는 `docs/og-image-prompt.txt`에 보존했습니다.

Open Graph와 Twitter 메타데이터를 HTML에 추가했습니다. 로컬 서버는 이미지 URL을 절대 주소로 치환합니다. 실제 서버 배포 시 `SITE_URL` 환경변수에 HTTPS 도메인을 지정하세요. 정적 호스팅에서는 HTML의 `__SITE_ORIGIN__`을 실제 도메인으로 치환해야 합니다. 현재 localhost 주소는 외부 메신저 크롤러가 접근할 수 없으므로 실제 링크 미리보기 확인은 배포 후 수행합니다.
